#  Risk Analytics in Banking and Financial Services

##  Project Overview
This project focuses on analyzing banking customer data to understand financial behavior and business lending patterns. The goal is to explore customer profiles, identify risk indicators, and derive meaningful insights using data analysis techniques.

This is an exploratory data analysis (EDA) project — no machine learning models were used.

---

##  Business Objective
The main objectives of this analysis are:

- Understand customer financial behavior
- Analyze business lending distribution
- Identify patterns in income, deposits, and loans
- Support better risk assessment decisions

---

##  Problem Context
Banks provide loans and other financial services, but lending involves financial risk. By analyzing customer data such as income, deposits, savings, and existing loans, we can understand:

- Which customers are more likely to take business loans
- How income impacts lending behavior
- How deposits and liabilities relate to risk exposure

---

##  Dataset Description

The dataset contains 3000 customer records with features such as:

| Feature | Description |
|----------|-------------|
| Age | Customer age |
| Estimated Income | Annual income |
| Bank Loans | Existing loans |
| Credit Card Balance | Outstanding balance |
| Bank Deposits | Total deposits |
| Saving Accounts | Savings amount |
| Business Lending | Business loan amount |
| Income Band | Income category |

---

##  Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI (for dashboard visualization)

---

##  Analysis Performed

### 1️⃣ Data Cleaning
- Removed unnecessary columns (Client ID, Name)
- Checked for missing values
- Verified data types

### 2️⃣ Exploratory Data Analysis (EDA)
- Distribution of Business Lending
- Income vs Business Lending analysis
- Deposits vs Loans comparison
- Credit Card Balance analysis
- Income Band segmentation

### 3️⃣ Visualization
- Bar charts
- Histograms
- Correlation heatmap
- Power BI interactive dashboard

---

## 📈 Key Insights

- Higher income customers tend to have higher business lending amounts.
- Customers with strong deposit balances show better lending capacity.
- Income Band significantly impacts financial product usage.
- Existing liabilities influence lending behavior.

---



##  Conclusion
This project demonstrates how exploratory data analysis can help banks understand customer financial behavior and assess lending patterns. The insights derived from this analysis can support data-driven risk management strategies.
